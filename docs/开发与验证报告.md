## 验证结果

### Python 与跨语言契约：39 项通过

命令：`python -m pytest tests -q`。原 Python 引擎内部测试的关键行为已改由 Go 测试覆盖，因此数量不能与 2.0.1 的 45 项直接比较。现有分页、搜索与归档测试实际调用 Go 二进制。

新增跨语言对照覆盖会话、联系人、活跃会话、消息、搜索、时间/发送人筛选和旧游标兼容；真实 Python SQLite 生成的 WAL 由 Go 合并，源 DB/WAL/SHM 哈希和修改时间不变。生产 Python 适配器连接真实 Go 管道、读取 20 万字原文并停止/重启。原生 helper 使用编译的虚构客户端验证暂停状态、解除暂停和 `CFFIXED_USER_HOME`，没有启动用户的企业微信。

覆盖：

- 真实 SQLite 三库快照；只读连接拒绝写操作。
- 正确及错误加密密钥、快照完整性校验失败后的清理。
- WAL 提交边界、损坏校验、加密页、截断和不同代次尾部处理。
- 真实 SQLite WAL 合并；源 DB/WAL/SHM 的内容 SHA-256 和修改时间保持不变。
- 三消息表同时间同消息号的 27 条消息完整分页，没有跨表误去重。
- 游标禁止跨账号、跨会话使用；protobuf 文本解码后搜索。
- 企业归档以 17 条小页补齐 221 条历史，新增 55 条后为 276 条，重复同步无重复。
- 归档来源/账号隔离，数据库和配置权限 0600，根目录权限 0700。
- 旧 archive.db 增加 message_key，同时保留旧消息主键与附件关联；旧归档仅被一个账号认领且等待确认。
- 鉴权拒绝未授权请求，个人 API 兼容，网关在来源离线时仍返回健康。
- AI 慢响应在来源、账号、会话选择或模型配置变化后返回 409，不回传分析内容。

- 企业 MCP 默认拒绝、专用凭据隔离、固定来源与账号、账号切换报错、撤销后立即拒绝。
- stdio 子进程连接实际本机 HTTP MCP，完成 initialize、initialized 通知、tools/list 和消息读取，得到六个工具及企业原文。
- Cursor JSON 和 Codex TOML 中个人/企业登记共存，撤销企业项保留个人项与其它配置。
- 管道长响应（15 万中文字符）、停止时取消钥匙串恢复任务、停止后重新启动。
- 归档任务在网关重启后保持来源和账号绑定。

## 使用边界与实机待验收

本次没有读取真实聊天、取真实密钥、修改当前 launchd 服务或启动/退出用户的官方客户端。已验证结果来自合成 SQLite 数据和隔离测试服务。

实机仍需验证：

- 当前个人微信及企业微信版本、账号发现与数据库字段是否匹配。
- 首次连接取钥、钥匙串持久化与 macOS 数据访问授权，尤其原生目录授权对后台进程的实际效果。
- 临时客户端副本启动、正常退出、恢复官方客户端及客户端更新后的连接兼容性。
- 真实高频写入、数据同步延迟、账号切换和大体积历史的长期稳定性。
- 真实 Codex、Claude、Cursor 的 MCP 握手、分页和工具调用。
- 使用真实模型服务的连接与回答质量。

企业微信暂未映射会话类型、本人身份、成员及媒体本体。界面/API 使用未知值或不支持状态，不推断成已验证能力。增量查询按游标排序；晚到且发送时间早于已归档游标的记录，以及历史回补行为，需要结合真实客户端进一步验收。

归档默认关闭；旧个人归档没有所属账号元数据，保留原目录后需要用户核对账号并恢复。安装包为开发版本，使用本机临时签名，没有 Developer ID 签名和 Apple 公证。
